Спелчеккер на английском языке

Версия: 1.1

Автор: Батырбаева Арина 

Описание:
Данная программа проверяет наличие орфографических ошибок в тексте, демонстрирует, 
в каких именно словах находятся ошибки и предлагает свои варианты исправлений

Требования: 
Python версии не ниже 3.6

Состав:
Консольная версия: spellchecker1.py
Алгоритм "Расстояние Левенштейна": edit_distance.py
Файл со словарем: words.txt 
Файл для проверки ошибок (для основной программы): mistakes.txt
Файл для проверки ошибок без ошибок (для основной программы и тестов): test_text.txt
Тесты: test_spellchecker.py
Файл с тестовым словарем: test_dict.txt

Консольная версия: 
Запуск из консоли: python spellchecker1.py
Cправка, вариант 1: python spellchecker1.py -h 
Справка, вариант 2: python spellchecker.py --help
